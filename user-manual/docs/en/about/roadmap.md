# Manual roadmap

This page summarizes what is available today and what is coming next. It is updated when new guides are published.

## Current status (Phase 2)

| Item | Status |
|------|--------|
| Manual site (four languages) | **Preview** — login guide draft |
| How-to guides | **Login**, **navigation**, **register**, **add passport** drafts |
| Green check (verified) | Enabled when guides pass automated tests |
| Full test reports | Separate internal report (not shown on this site) |

## Planned guide order

1. Getting started — login and navigation  
2. Find and open a person  
3. Register a new employee and add a passport  
4. Update person details  
5. Create an application and add items  

Advanced topics (document copies, dossier, report packages, templates) follow after basic person and application tasks.

## Publication

Technical staff publish this site after automated checks pass. Guide content is reviewed for accuracy before it is marked published.
