# Visa2026 User Manual

Welcome to the **Visa2026 officer user manual**. This site explains daily tasks step by step using the same labels you see in the application.

## What you will find here

| Section | Purpose |
|---------|---------|
| **Getting started** | Sign in, navigation, roles |
| **How-to guides** | Task-based instructions (coming in the next release) |
| **Reference** | Field and screen help generated from the application catalog |

## Languages

Use the language menu at the top to switch between **English**, **Turkish**, **Turkmen**, and **Russian**.

Guides are published in English first; other languages follow the same curriculum order.

**Start here:** [Sign in](getting-started/login.md) then [Register an employee](guides/person/register.md) (tier 0-2 drafts).

## Verified guides

When a guide has passed automated testing on the published build, you will see a **green check** next to its title. That mark means the steps were exercised in a test environment — your officer reviewer still confirms accuracy before publication.

## Need help?

Contact your visa office supervisor or system administrator if a screen in the application does not match this manual.
