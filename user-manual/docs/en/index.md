# Visa2026 User Manual

Welcome to the **Visa2026 officer user manual**. This site explains daily tasks step by step using the same labels you see in the application.

## What Visa2026 helps you do

Visa2026 gives the visa department **one place** to manage foreign workers and their migration paperwork. The most important areas, in order:

1. **Report Dashboard** — see what needs action today (expiring documents, open cases, incomplete records)
2. **Person master data** — keep passports, visas, medical records, and addresses complete per employee, family member, or temporary visitor
3. **Applications** — prepare ministry and direct-migration requests with one header and per-person lines
4. **Application progress** — track where each case is (office, ministry, migration service)
5. **Document copies & Templates** — build ministry PDF packages and Word/Excel report ZIPs with readiness checks

For the full list with the **problem each area solves**, see **[What Visa2026 does](about/capabilities.md)**.
