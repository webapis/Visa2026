# Referans özeti

**Referans** bölümü, Visa2026 ekran başlıklarıyla eşleşen alan etiketleriyle iş nesnelerini (kişi, başvuru ve ilgili kayıtlar) listeleyecektir.

Referans sayfaları sonraki sürümde uygulama kataloğundan **otomatik üretilir**. Dahili kod adları gösterilmez — yalnızca görevlilerin arayüzde gördüğü etiketler.

## Yakında

- Kişi  
- Başvuru  
- Başvuru kalemi  
- Başvuru ilerlemesi
