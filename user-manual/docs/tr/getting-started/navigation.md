# Ana gezinme

Bu kılavuz, oturum açtıktan sonra Visa2026'da nasıl gezineceğinizi anlatır: ana sayfa, sol menü, listeler, ayrıntı formları ve üst araçlar.

!!! tip "Ön koşul"
    Önce [Visa2026'ya giriş](login.md) kılavuzunu tamamlayın; **Rapor Panosu** açılmalıdır.

!!! tip "Ekran görüntüleri"
    Görseller **İngilizce** arayüzden alınmıştır (sürüm **2026.08**). Etiketler dilinize göre değişir; adımlar aynıdır.

## Uygulama kabuğu

Oturum açtıktan sonra dört ana alan görürsünüz:

| Alan | Amaç |
|------|------|
| **Üst çubuk** | Başlık, bildirim zili, kullanıcı menüsü |
| **Gezinme menüsü** (sol) | Listeleri ve çalışma alanlarını açma |
| **Ana içerik** (orta) | Pano, listeler veya ayrıntı formları |
| **Araç çubuğu** | **Yeni**, **Kaydet**, **Yenile** gibi işlemler |

![Uygulama kabuğu ve sol menü](../../assets/screenshots/v2026.08/tr/navigation-step-01-shell.png)

## Ana sayfa — Rapor Panosu

Girişten sonra **Rapor Panosu** açılır. Özet grafikleri inceleyin ve ilgili listelere geçin.

- Kategoriler arasında geçiş yapın
- Kartın sağ üstündeki **Yenile** ile verileri güncelleyin
- **Listeyi Aç** ile eşleşen kayıtları görün

Sol menüden **Rapor Panosu** ile her zaman dönebilirsiniz.

## Sol gezinme menüsü

Rolünüze göre menü öğeleri değişir. Görevliler genelde şunları görür:

| Menü | Amaç |
|------|------|
| **Rapor Panosu** | Ana sayfa |
| **Çalışanlar** | Çalışan kayıtları |
| **Aile Üyeleri** | Aile üyesi kayıtları |
| **Geçici ziyaretçi** | Geçici ziyaretçi kayıtları |
| **Başvurular** | Başvuru üst kayıtları |
| **Başvurular (bakanlık süreci)** / **Başvurular (doğrudan migrasyon)** | İş akışına göre başvurular |
| **Davet** / **Ret** / **Çalışma İzni** | İlgili iş akışları |
| **Operasyonlar** | Görevli araçları |
| **Raporlar** | Kullanıcı rapor şablonları (rolünüz izin veriyorsa) |

!!! note "Menünüz farklı olabilir"
    Eksik menü için yöneticinize başvurun — başka birinin hesabını kullanmayın.

![Sol gezinme menüsü](../../assets/screenshots/v2026.08/tr/navigation-step-02-left-menu.png)

## Liste açma

1. Sol menüden **Çalışanlar**'ı seçin.
2. Listenin yüklenmesini bekleyin.

Araç çubuğunda **Yeni**, **Yenile** ve arama bulunur.

![Çalışanlar listesi](../../assets/screenshots/v2026.08/tr/navigation-step-03-employees-list.png)

## Ayrıntı formu açma

1. Listeden bir satır seçin.
2. Ayrıntı formu açılır.

Sekmeler (ör. **Pasaportlar**, **Eğitim**) ilgili alt bilgiler içindir.

| İşlem | Ne zaman |
|-------|----------|
| **Kaydet** | Değişiklikten sonra |
| **Kaydet ve Kapat** | Kaydedip listeye dönme |
| **Yenile** | Görünümü yenileme |

![Çalışan ayrıntı formu](../../assets/screenshots/v2026.08/tr/navigation-step-04-detail-form.png)

!!! warning "Kaydedilmemiş değişiklikler"
    **Kaydet**meden başka menüye geçmeyin.

## Üst çubuk

- **Bildirim zili** — **Durum bildirimleri** (süresi dolan belgeler vb.)
- **Kullanıcı menüsü** — **Hesabım**, **Şifre Değiştir**, **Çıkış**

Tam liste için **Operasyonlar → Durum bildirimleri**.
