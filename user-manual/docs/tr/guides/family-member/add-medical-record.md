# Tıbbi kayıt ekleme

**Medical Records** sekmesinden tıbbi kayıt ekleyin.

<video class="visa-manual-video" controls preload="metadata"
  src="../../../assets/videos/v2026.08/tr/person-add-medical-record.mp4"
  title="Tıbbi kayıt ekleme"></video>

## Adımlar

1. Çalışanı açın → **Medical Records** sekmesi.
2. **New Medical Record**.
3. **Document Number** girin; **Issue Date** ve **Validity Duration** değerlerini kontrol edin.
4. **Save** → **Expiration Date** otomatik hesaplanır.
