# İkamet adresi ekleme

**Addresses Of Residence** sekmesinden ikamet adresi ekleyin. Varsayılan **Type** = **Lodging**.

## Adımlar (Lodging)

1. **New Address Of Residence**.
2. Sırayla **Region** → **City** → **Lodging** seçin (arama + listeden).
3. **Expiration Date** girin.
4. **Save**.
