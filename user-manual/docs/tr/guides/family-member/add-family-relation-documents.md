# Aile ilişkisi belgeleri ekleme

**Aile üyesi** için evlilik/doğum belgesi gibi dosyalar **Family relation documents** sekmesine yüklenir.

!!! tip "Ön koşul"
    [Aile üyesi kaydı](register.md).

## Adımlar

1. Aile üyesi ayrıntı formunu açın.
2. **Family relation documents** sekmesi → **New**.
3. **File** alanından dosyayı seçin → **Save**.
