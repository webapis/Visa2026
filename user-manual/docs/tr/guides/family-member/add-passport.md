# Aile üyesine pasaport ekleme

Bu kılavuz mevcut bir **aile üyesine** **pasaport** kaydı eklemeyi anlatır. Pasaportlar, aile üyesi ayrıntı formundaki **Passports** sekmesinden eklenir.

!!! tip "Ön koşul"
    Aile üyesi kaydı olmalıdır ([Aile üyesi kaydı](register.md)).

!!! tip "Ekran görüntüleri"
    Görseller **İngilizce** arayüzden (sürüm **2026.08**).

## Adım 1 — Aile üyesini açın

1. [Kişiyi bulun ve açın](../person/open-and-search.md) — **Family Members** listesini kullanın.
2. **Passports** sekmesinin göründüğü ayrıntı formunu bekleyin.

## Adım 2 — Passports sekmesi

1. **Passports** sekmesini seçin.
2. İç listede **New Passport** düğmesini bulun.

## Adım 3 — Yeni pasaport

1. **New Passport** seçin.
2. Zorunlu alanları doldurun (**Passport Number**, **Passport Type**, tarihler, **Authority**, **Issued Country**).
3. **Save** seçin.
