# Bakanlık belge kopyaları (PDF paketi)

**Application item** satırlarında **Document copies** — tarama hazırlığı, önizleme ve **ministry PDF ZIP** paketi.

!!! tip "Ön koşullar"
    [Application items ekleme](add-items.md); kişi kayıtlarında taramalar hazır olmalı.

## Nereden açılır

| Liste | Menü |
|-------|------|
| Bakanlık | **Application items (ministry)** |
| Doğrudan göç | **Application items (migration)** |
| Başvuru detayı | **Application items** sekmesi |

## Adımlar

1. Bir veya daha fazla satır seçin.
2. Araç çubuğu → **Document copies** (sağ önizleme paneli).
3. **Linked documents** — durum (Ready / Partial / Missing); isteğe bağlı **gear** ayrıntıları.
4. **Preview** — tarama yuvası; **Application form** satırında önizleme yerine doğrudan indirme.
5. İsteğe bağlı **Package options**.
6. **Download package** — eksik dosya uyarısını onaylayın veya iptal edin.
7. **PDF generation** toast → ZIP indirin.
8. Tarama ekledikten sonra **Refresh**.

## Sık sorunlar

| Sorun | Çözüm |
|-------|--------|
| Düğme kapalı | Satır seçin |
| Missing | Kişiye tarama ekleyin → **Refresh** |
| Toast bitmiyor | Bekleyin; IT |
