# Applications — bakanlık ve doğrudan göç

Visa2026 başvuru işini **iki rota** altında ayırır. Her rotanın kendi **başlık listesi** ve **application items listesi** vardır.

## İki rota

| Rota | Başlık listesi | Application items listesi | Ne zaman |
|------|----------------|---------------------------|----------|
| **Bakanlık üzerinden** | **Applications (via ministry)** | **Application items (ministry)** | Bakanlık onayı, sonra göç |
| **Doğrudan göç** | **Applications (direct migration)** | **Application items (migration)** | Doğrudan göç müdürlüğü |

## Applications menüsü (dört liste)

1. **Applications (via ministry)** — bakanlık rotası başlıkları
2. **Applications (direct migration)** — doğrudan göç başlıkları
3. **Application items (ministry)** — bakanlık rotası kişi satırları
4. **Application items (migration)** — doğrudan göç kişi satırları

## Applications (via ministry)

Bakanlık incelemesi gereken işlemler (davetiye, vize uzatma vb.).

| Görev | Menü |
|-------|------|
| Yeni başvuru | **Applications (via ministry)** → **New** |
| Kişi ekle | Başlık → **Application items** → **New** |

## Applications (direct migration)

Doğrudan göç müdürlüğüne giden işlemler (kayıt check-in/out vb.).

| Görev | Menü |
|-------|------|
| Yeni başvuru | **Applications (direct migration)** → **New** |
| Kişi ekle | Başlık → **Application items** → **New** |

## Tipik akış

1. Doğru **başlık listesini** açın.
2. **New** → tür ve başlık → **Save**.
3. **Application items** → her kişi için **New** → **Save**.
