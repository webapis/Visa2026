# Başvuru oluşturma

Bu kılavuz yeni bir **application** (başvuru başlığı) oluşturmayı anlatır — bakanlık veya göç talebi için ortak dosya.

**İki başlık listesi:** **Applications (via ministry)** veya **Applications (direct migration)** — hangi listeyi açacağınız için [Applications — bakanlık ve doğrudan göç](overview.md).

Kişi satırları (**application items**) ayrı bir kılavuzda eklenir.

!!! tip "Ön koşullar"
    [Giriş](../../getting-started/login.md), [Ana gezinme](../../getting-started/navigation.md), [Applications özeti](overview.md) ve hazır kişi kayıtları ([Çalışan kaydı](../employee/register.md)).

## Başlamadan önce

| Gereken | Not |
|---------|-----|
| Doğru başlık listesi | **Applications (via ministry)** *veya* **Applications (direct migration)** |
| **Application Type Code** | Üç haneli bakanlık kodu — liste türüne göre filtrelenir |
| Sözleşme / aciliyet | Türde görünen alanlar |

| Liste | Ne zaman |
|-------|----------|
| **Applications (via ministry)** | Bakanlık onayı gereken işlemler |
| **Applications (direct migration)** | Doğrudan göç müdürlüğü işlemleri |

## Adım 1 — Doğru Applications listesini açın

### Applications (via ministry)

1. Sol menü → **Applications** → **Applications (via ministry)**.
2. Liste yüklenene kadar bekleyin.
3. Araç çubuğunda **New** olmalı.

### Applications (direct migration)

1. Sol menü → **Applications** → **Applications (direct migration)**.
2. Liste yüklenene kadar bekleyin.
3. Araç çubuğunda **New** olmalı.

!!! warning "Listeler ayrıdır"
    Bakanlık rotasında oluşturulan başvuru yalnızca **Applications (via ministry)** listesinde görünür. Doğrudan göç başvuruları **Applications (direct migration)** listesindedir.

## Adım 2 — Yeni başvuru

**New** → boş başvuru formu açılır. **Application Date** genelde bugün.

## Adım 3 — Başvuru türü

1. **Application Type Code** girin veya **…** ile listeden seçin.
2. **Application Type** adı dolar; forma özel alanlar görünür.

Tür kodu listede yoksa yanlış rotadasınız — [özete](overview.md) bakın.

## Adım 4 — Başlık alanları

**Project Contract**, **Urgency**, vize alanları, sınır bölgesi vb. — türe göre doldurun.

## Adım 5 — Kaydet

**Save** → **Full Application Number** atanır; **Progress history** başta boş kalır (ofiste hazırlık örtük kabul edilir).

## Adım 6 — Listede doğrulayın

**Aynı listede** (via ministry veya direct migration) numarayı bulun; **Application items** sekmesi başta boştur.
