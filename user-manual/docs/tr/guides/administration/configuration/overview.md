# Yapılandırma genel bakış

**Configuration** menüsü şirket kimliği, başvuru numaralandırma, onay rotaları, SLA ve yükleme sınırlarını yönetir. Çoğu memur bu menüyü görmez; **VisaOffice** / yönetici hesapları kullanır.

## Menü özeti

| Menü | Kılavuz |
|------|---------|
| Company, Application Numbering, Authorized Signatory, Authorized Representative | [Kuruluş ayarları](organization.md) |
| Project contracts, Approving ministries, Approval Leg Profile | [Sözleşmeler ve onaylar](contracts-and-approvals.md) |
| Application Migration Sla Profile, Ministry review SLA | [SLA ayarları](sla.md) |
| Document expiration alerts, Upload limits | [Uyarılar ve yükleme sınırları](alerts-and-upload-limits.md) |

## Adımlar

1. **VisaOffice** veya yönetici ile giriş yapın.
2. Sol menüden **Configuration**'ı açın.
3. İlgili alt öğeyi seçin — tekil kayıtlarda yeni satır oluşturmayın.

Rapor şablonları: [Kullanıcı rapor şablonları](../user-report-templates.md).
