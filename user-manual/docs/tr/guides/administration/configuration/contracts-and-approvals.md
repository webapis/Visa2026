# Sözleşmeler ve onaylar

**Approving ministries** → kısa bakanlık adları. **Approval Leg Profile** → sıralı bakanlık zinciri. **Project contracts** → başvuruda seçilen sözleşme; bir profile bağlı.

## Özet adımlar

1. Bakanlıkları **Approving ministries**'te tanımlayın.
2. **Approval Leg Profile**'da **Ministry legs** sırasını ayarlayın.
3. **Project contracts**'ta profile bağlayın ve **Is Active** işaretleyin.
