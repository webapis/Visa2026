# Uyarılar ve yükleme sınırları

**Document expiration alerts** — belge türü başına son kullanma öncesi takvim günü. **Upload limits** — görsel ve ek dosya MB üst sınırı (sunucu tavanı geçilemez).

Vize / çalışma izni kalemi için isteğe bağlı **uzatma başvurusu günü** alanı görünür.
