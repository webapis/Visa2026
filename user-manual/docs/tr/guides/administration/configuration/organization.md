# Kuruluş ayarları

Dört **tekil** kayıt: **Company**, **Application Numbering**, **Authorized Signatory**, **Authorized Representative**.

## Özet

| Menü | Alanlar |
|------|---------|
| **Company** | Ad, kod (antet), adres, telefon, e-posta, vergi |
| **Application Numbering** | Önek, format (`{PREFIX}`, `{YEAR}`, `{NUMBER}` …), padding, seed |
| **Authorized Signatory** | Ad, pozisyon (Tm), pasaport |
| **Authorized Representative** | Ad, pozisyon, telefon, pasaport |

Her listede **tek satır** düzenleyin; yinelenen oluşturmayın. **Save** sonrası [Resminamalar](../../applications/resminamalar.md) birleştirmeleri güncellenir.
