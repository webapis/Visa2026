# Gecici ziyaretci kaydi

Visa2026'da yeni **gecici ziyaretci** kaydı oluşturmayı anlatır. Liste: **Temporary visitor**.

## Adımlar

1. **Temporary visitor** listesini açın → **New**.
2. Zorunlu kişi alanlarını ve **Project Contract**, **Company (Subcontractor)** doldurun.
3. **Sponsoring Employee** veya **Relationship** kullanmayın — bunlar aile üyelerine özeldir.
4. **Save** → listede doğrulayın.
