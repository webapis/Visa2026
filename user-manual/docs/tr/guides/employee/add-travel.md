# Seyahat gecmisi ekleme

Calisan ayrintı formunda **Travel Histories** sekmesinden seyahat kaydi ekleyin (calisan ve gecici ziyaretci; aile uyesinde bu sekme yok).

1. Calisani acin → **Travel Histories** sekmesi.
2. **New** bolunmus dugmesinde ok → **New External Arrival**.
3. **Travel Date**, **Check Point**, **Country** dogrulayin → **Save**.
4. Listede dogrulayin.
