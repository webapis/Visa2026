# Is gorevi ekleme

Calisan ayrintı formunda **Work Duties** / **Gelmeginiň Maksady** sekmesinden is gorevi ekleyin (yalnizca calisan).

1. Calisani acin → **Work Duties** sekmesi.
2. **New Work Duty** → aciklama alanini doldurun → **Save**.
3. Listede dogrulayin.
