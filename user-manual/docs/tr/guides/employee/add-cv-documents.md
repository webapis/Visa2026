# CV ve kisisel dosya ekleme

Calisan ayrintı formunda **CV & personal files** sekmesinden CV veya kisisel dosya yukleyin (yalnizca calisan).

1. Calisani acin → **CV & personal files** sekmesi.
2. **New** / **New Person Document** → **File** alanina dosya secin → **Save**.
3. Listede dogrulayin.

Pasaport veya diploma taramalari bu sekmede degil; ilgili pasaport / egitim kaydinda **Passport copies** / **Diploma copies** kullanin.
