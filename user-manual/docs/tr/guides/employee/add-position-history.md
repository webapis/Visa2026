# Pozisyon geçmişi ekleme

**Position History** sekmesinden görev geçmişi ekleyin (çalışan kayıtları).

## Adımlar

1. **New Employee Position History**.
2. **Position (visa reports)** ve **Position (actual / company)** seçin.
3. **Start Date** (ve gerekiyorsa **End Date**) girin.
4. **Save**.
