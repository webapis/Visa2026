# Maas kaydi ekleme

Calisan ayrintı formunda **Salaries** sekmesinden maas kaydi ekleyin (yalnizca calisan).

1. Calisani acin → **Salaries** sekmesi.
2. **New Employee Salary** → **Amount**, **Currency** doldurun → **Save**.
3. Listede dogrulayin.
