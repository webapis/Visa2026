# İkamet adresi ekleme

**Addresses Of Residence** sekmesinden ikamet adresi ekleyin. Varsayılan **Type** = **Lodging**.

## Adımlar (Lodging)

1. **New Address Of Residence**.
2. Sırayla **Region** → **City** → **Lodging** seçin (arama + listeden).
3. **Expiration Date** girin.
4. **Save**.

![Adres formu](../../../assets/screenshots/v2026.08/tr/person-add-address-step-03-address-fields-filled.png)

## Konaklama / otel / hastane (kiracı katalog)

**Lodging**, **Hotel**, **Hospital**, **Other site** bu adres formundan eklenir. Listede yoksa alanda **New** — **Full address** veya **Name** + **City**. **New** öncesi arayın; aynı tesisi iki kez eklemeyin.
