# Kişi belge kopyaları

Bir kişinin tüm tarama dosyalarını tek **önizleme panelinde** bölümler halinde görüntüleyin. Bakanlık PDF ZIP için [Başvuru belge kopyaları](../applications/document-copies.md) kullanın.

## Giriş noktaları

| Yer | Denetim |
|-----|---------|
| Kişi detay formu | **Person document copies** (Kişi belge kopyaları) |
| Liste | **Dossier** sonrası **•** sütunu |
| Dosya (dossier) | **Document copies** |

## Özet adımlar

1. Kataloğu açın — sağ panel.
2. Bölümlerde pasaport, vize, eğitim, tıbbi kayıt vb. satırları inceleyin.
3. **Ready** satırda **Preview** veya satıra tıklayın.
4. **Download** / **Close** ile önizlemeyi yönetin.
5. Tarama ekledikten sonra **Refresh**.

**Show all documents** / **Show current only** — geçmiş pasaport ve vizalar.

Detay: [Kişi dosyası](dossier.md).
