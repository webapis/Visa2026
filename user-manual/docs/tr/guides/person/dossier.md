# Kişi dosyası (dossier)

Bir kişinin salt okunur **360° özeti** — düzenleme için detay formu değil.

!!! tip "Ön koşullar"
    [Kişi bulma](open-and-search.md).

## Giriş noktaları

| Yol | Nereden |
|-----|---------|
| **Open dossier** | Kişi detay araç çubuğu |
| **Dossier** sütunu | Employees / Family Members / Temporary visitor listesi |
| **Person search** | Report Dashboard → satıra tıkla |

## Adımlar

1. Dosyayı açın — yükleme panelini bekleyin.
2. Kimlik ve durum kutularını okuyun (pasaport, vize, çalışma izni, kayıt).
3. **Screen** / **Paper** görünümü.
4. **Document copies** → sağ panelde kişi taramaları.
5. Düzenleme için listeye dönüp satıra tıklayın (Dossier değil).
6. **Export for director** → toast → ZIP (yönetici teslimi).

## Sık sorunlar

| Sorun | Çözüm |
|-------|--------|
| Open dossier kapalı | Kişiyi önce kaydedin |
| Düzenleme gerek | Detay formunu açın |
