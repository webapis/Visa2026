# Durum bildirimleri

!!! danger "Ertelendi"
    Bu özellik ofiser kılavuzunda **yok**. [Rapor Panosu](report-dashboard.md) ve [Eksik işaretleme](../person/mark-incomplete.md) kullanın.

**State notifications** — süresi dolan belgeler ve eksik veri için planlanan gelen kutusu. **Şu an:** **UI prototype** örnek satırlar; yalnızca **yöneticiler** — **Operations → State notifications**.

## Özet

1. Yönetici hesabıyla **Operations → State notifications** açın.
2. **Critical** / **Warning** / **Missing data** özetlerine tıklayarak filtreleyin.
3. Kartlarda örnek uyarıları okuyun — canlı veri değil.
4. **Sync states** ve **Open person** şimdilik yalnızca gösterim.

Memur erişimi ve canlı değerlendiriciler sonraki fazda. Bkz. [Rapor Panosu](../tracking/report-dashboard.md), [Eksik işaretleme](../person/mark-incomplete.md).
