# Rapor Panosu

Girişten sonra açılan **Rapor Panosu** ile vize, davet, başvuru, kayıt ve benzeri alanlarda durumu grafiklerle izlersiniz; listeye iner veya Excel’e aktarırsınız.

## Özet adımlar

1. **Rapor Panosu** menüsünü açın (girişte varsayılan sayfa).
2. **Genel bakış** kartından bir kategori seçin (Vize, Davet, Bakanlık yoluyla başvuru vb.).
3. Grafikte dilim/satıra tıklayarak önizleme tablosunu filtreleyin.
4. **Listeyi aç** ile tam salt okunur listeyi açın.
5. Yapılandırıldıysa **Excel’de aç** ile indirin.
6. Değişikliklerden sonra **Yenile** kullanın.

## Person arama

**Kişi arama** kategorisinde ad, kişisel numara veya pasaport numarası yazın; satıra tıklayınca [kişi dosyası](../person/dossier.md) açılır (düzenleme formu değil). Bkz. [Kişi bulma](../person/open-and-search.md).

## Eksik verili kişiler

**Verileri eksik kişiler** kategorisi manuel **Eksik** bayrağını gösterir. Bkz. [Eksik işaretleme](../person/mark-incomplete.md).

## Sık sorunlar

| Sorun | Çözüm |
|-------|--------|
| Sıfır sayılar | **Yenile**; ortam verisi az olabilir |
| Excel kapalı | Şablon yok — yöneticiye başvurun |
| Zil bildirimleri | Otomatik süre uyarıları; panodan ayrı özellik |
