# Gollanma ýol kartasy

Bu sahypa häzir nämeleriň barlygyny we indiki nämeleriň geljekdigini gysgaça beýan edýär. Täze gollanmalar çykanda täzelenýär.

## Häzirki ýagdaý (2-nji faz)

| Element | Ýagdaýy |
|---------|---------|
| Gollanma saýty (dört dil) | **Öňünden görmek** — giriş we gezim garalamalary |
| Nädip edilýär gollanmalary | **Giriş** + **gezim** garalamalary; işgär hasaba alyş indiki |
| Ýaşyl bellik (barlanan) | Gollanmalar synagdan geçende işjeň |
| Doly synag hasabatlary | Aýratyn içerki hasabat (bu saýtda görkezilmeýär) |

## Meýilleşdirilen gollanma tertibi

1. Başlangyç — giriş we gezim  
2. Şahsy tapmak we açmak  
3. Täze işgär hasaba almak we pasport goşmak  
4. Şahsy maglumatlary täzelemek  
5. Arza döretmek we element goşmak  

Ösen mowzuklar (resminama nusgalary, dosye, hasabat paketleri, şablonlar) esasy şahsy we arza wezipelerinden soň gelýär.

## Neşir

Tehniki topar awtomatiki barlaglar geçenden soň bu saýty neşir edýär. Gollanma mazmuny neşirden öň takyklyk üçin gözden geçirilýär.
