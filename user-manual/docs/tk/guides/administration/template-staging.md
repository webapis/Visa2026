# Şablony redaktirle we bazaga sinhronla

**Templates** panelinden kompýuterde Word/Excel redaktirleme we **Sync to database**.

## Gysga ädimler

1. Arzada **Templates** açyň.
2. Bir gezek: **Change template folder** — `%LOCALAPPDATA%\Visa2026\TemplateEdit`
3. **Tigir** bilen **Edit template** görkeziň.
4. Redaktirle, ýazdyr, Word/Excel ýapyň.
5. **Sync to database**.
6. **Refresh** we **Preview**.

[Ulanyjy hasabat şablonlary](user-report-templates.md).
