# Doly däl diýip bellemek we tamamlamak

Bu gollanma esasy maglumatlary heniz doly däl adamy **Incomplete** hökmünde bellemegi, näme ýetmezçiligini ýazmagy we taýýar bolanda belgini arassalamagy görkezýär.

**Incomplete** baydagy ýumşak ýatlatmadyr — arza döretmegi **bloklaýan däl**.

    [Adamy tapmak we açmak](open-and-search.md).

    Suratlar **Iňlis** interfeýsinden (wersiýa **2026.08**).

## Başlamazdan öň

| Gerek | Bellik |
|-------|--------|
| **Employees** / **Family Members** / **Temporary visitor** | Sanawdan däl, jikme-jik formada |
| Azyndan bir meýdan we **Notes** | **Mark incomplete** üçin hökmany |

## Ädim 1 — Jikme-jik formany açyň

![Jikme-jik forma](../../../assets/screenshots/v2026.08/tk/person-mark-incomplete-step-01-detail-form.png)

## Ädim 2 — Mark incomplete

1. Gural panelinde **Mark incomplete** saýlaň.
2. **Mark person incomplete** penjiresinde azyndan bir gutusy belläň: **Personal data**, **Passport**, **CV**, **Photo**, **Education**, **Medical**, **Address**, **Family docs**, **Other**.
3. **Notes** ýazyň (hökmany).
4. **Apply** saýlaň.

## Ädim 3 — Incomplete data sekmesi

**Incomplete data** sekmesinde diňe okamak: **Missing areas**, **Incomplete notes**, **Incomplete marked on**, **Incomplete marked by**.

![Incomplete data sekmesi](../../../assets/screenshots/v2026.08/tk/person-mark-incomplete-step-03-incomplete-tab.png)

## Ädim 4 — Update incomplete

**Update incomplete** → üýtget → **Apply**.

## Ädim 5 — Report Dashboard

**Report Dashboard** → **Persons with incomplete data**.

![Report Dashboard](../../../assets/screenshots/v2026.08/tk/person-mark-incomplete-step-04-dashboard.png)

## Ädim 6 — Mark complete

**Mark complete** → tassykla: *Clear incomplete status and notes for this person?*

!!! success "Tamamlandy"
    Adam indi incomplete sanawynda görünmez.
