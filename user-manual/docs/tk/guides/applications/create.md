# Arza döretmek

Bu gollanma täze **application** (arza başy) döretmegi görkezýär.

**Iki başlyk sanawy:** **Applications (via ministry)** ýa-da **Applications (direct migration)** — [Applications — ministrlik we göni migrasiýa](overview.md).

Adamlar **application items** tabynyň içinde goşulýar (aýratyn gollanma).

!!! tip "Öňünden"
    [Giriş](../../getting-started/login.md), [Nawigasiýa](../../getting-started/navigation.md), [Applications gysgaça](overview.md).

## Adym 1 — Dogry başlyk sanawy

### Applications (via ministry)

**Applications** → **Applications (via ministry)** → **New** (ministrlik ugry).

### Applications (direct migration)

**Applications** → **Applications (direct migration)** → **New** (göni migrasiýa).

!!! warning "Sanawlar aýratyn"
    Ministrlik arzasy diňe **via ministry** sanawynda; göni migrasiýa arzasy — **direct migration** sanawynda.

## Adym 2 — Application Type Code

3 sanly kod ýa-da **…** sanawy → **Application Type** dolar.

## Adym 3 — Başlyk meýdanlary we ýatda saklamak

**Project Contract**, **Urgency** we ş.m. → **Save** → **Full Application Number**.

## Adym 4 — Barlamak

Şol bir sanawda (via ministry ýa-da direct migration) tapyň.
