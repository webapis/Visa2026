# Applications — ministrlik we göni migrasiýa

Visa2026 arza işini **iki ugur** boýunça bölýär. Her ugurda aýratyn **başlyk sanawy** we **application items sanawy** bar.

## Iki ugur

| Ugur | Başlyk sanawy | Application items sanawy |
|------|---------------|--------------------------|
| **Ministrlik arkaly** | **Applications (via ministry)** | **Application items (ministry)** |
| **Göni migrasiýa** | **Applications (direct migration)** | **Application items (migration)** |

## Applications menýusy (dört sanaw)

1. **Applications (via ministry)** — ministrlik ugry başlyklary
2. **Applications (direct migration)** — göni migrasiýa başlyklary
3. **Application items (ministry)** — ministrlik setirleri
4. **Application items (migration)** — göni migrasiýa setirleri

## Tipik akym

1. Dogry başlyk sanawyny açyň.
2. **New** → görnüş we başlyk → **Save**.
3. **Application items** → her adam üçin **New**.
