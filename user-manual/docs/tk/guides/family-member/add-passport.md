# Maşgala agzasyna pasport goşmak

Bu gollanma bar bolan **maşgala agzasyna** **pasport** ýazgysyny goşmagy görkezýär. Pasportlar maşgala agzasynyň jikme-jik formasyndaky **Passports** tabynyň içinde döredilýär.

!!! tip "Öňünden"
    Maşgala agzasy ýazgysy bolmaly ([Maşgala agzasyny hasaba almak](register.md)).

## Adym 1 — Maşgala agzasyny açyň

1. [Adamy tapyň we açyň](../person/open-and-search.md) — **Family Members** sanawy.
2. **Passports** tabynyň görünýän jikme-jik formasyny garaşyň.

## Adym 2 — Täze pasaport

1. **New Passport** saýlaň.
2. Zerur meýdanlary dolduryň → **Save**.
