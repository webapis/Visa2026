# Add an address of residence (temporary visitor)

Add an **address of residence** on a temporary visitor from **Person record data** → **Addresses Of Residence**.

Default **Type** is usually **Lodging**.

!!! tip "Prerequisites"
    The temporary visitor must exist ([Find and open a person](../person/open-and-search.md)).

## Steps (Lodging)

1. **New Address Of Residence**.
2. Set **Region** → **City** → **Lodging** (lookup chain).
3. Enter **Expiration Date** → **Save**.
