# Add a medical record (temporary visitor)

Add a **medical record** on a temporary visitor from **Person record data** → **Medical Records**.

!!! tip "Prerequisites"
    The temporary visitor must exist ([Find and open a person](../person/open-and-search.md)).

## Steps

1. Open the temporary visitor detail form.
2. **Medical Records** → **New Medical Record**.
3. Enter **Document Number**; confirm **Issue Date** and **Validity Duration** → **Save**.
