# Pasporta wiza goşmak

**Visas** goýmasynda pasporta **wiza** goşuň. Öň pasport bolmaly ([Pasport goşmak](add-passport.md)).

1. Işgäri açyň → **Passports** → pasporty açyň.
2. **Visas** → **New Visa**.
3. **Process number**, **Visa Number**, görnüşler we seneleri dolduryň → **Save**.
