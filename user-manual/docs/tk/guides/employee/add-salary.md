# Alyp berme yazgysy goşmak

Ishgär formasynda **Salaries** sekmesinden alyp berme ýazgysy goşuň (diňe işgär).

1. Ishgäri açyň → **Salaries** sekmesi.
2. **New Employee Salary** → **Amount**, **Currency** dolduryň → **Save**.
3. Sanawda tassyklaň.
