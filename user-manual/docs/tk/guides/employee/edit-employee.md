# Işgäriň maglumatlaryny täzelemek

Bu gollanma bar bolan **işgär** ýazgysyndaky meýdanlary üýtgetmek we ýatda saklamagy görkezýär.

!!! tip "Öňünden"
    [Adamy tapmak we açmak](../person/open-and-search.md) we [Täze işgär hasaba almak](register.md).

!!! tip "Ekran suratlary"
    Suratlar **Iňlis** interfeýsinden (wersiýa **2026.08**).

## Wideo gollanma

## Başlamazdan öň

| Gerek | Bellik |
|-------|--------|
| **Employees** üzerinde üýtgetmek ygtyýasy | Meýdanlar diňe okamak bolsa ýolbaşçyňyza ýüz tutuň |
| Dogry işgäriň jikme-jik formasy açyk | [Adamy tapmak we açmak](../person/open-and-search.md) |

Bu gollanma işgäriň esasy meýdanlaryny täzelär. Pasport we okuw sekmeleri üçin aýratyn gollanmalar bar.

## Ädim 1 — Jikme-jik formany açyň

1. Giriň.
2. **Employees** sanawyny açyň.
3. Gerek bolsa gözläň.
4. Setire basyň.

**Personal Number** we **Full Name** dogrulygyny barlaň.

![Üýtgetmek üçin jikme-jik forma](../../../assets/screenshots/v2026.08/tk/person-edit-employee-step-01-detail-form.png)

## Ädim 2 — Meýdanlary üýtgediň

| Meýdan | Haçan |
|--------|-------|
| **Foreign Address** | Daşary salgy üýtgedi |
| **Foreign Address Country** | Salgy ýurdy üýtgedi |
| **Email** | Habarlaşyk (goşmaça — ädim 3) |
| **Project Contract** | Şertnama üýtgedi |
| **Company (Subcontractor)** | Subpudarçy üýtgedi |
| **Marital Status** | Maşgalaly ýagdaýy |

!!! warning "Personal Number"
    **Personal Number** esasy identifikatordyr. Diňe ýolbaşçyňyz tassyklasa üýtgediň.

## Ädim 3 — Goşmaça meýdanlar (dişli)

1. **Show optional fields** / **Goşmaça meýdanlary görkez** (dişli) saýlaň.
2. **Middle Name**, **Email**, **Photo**, **Hire Date** görünýär.
3. Üýtgediň.
4. **Hide optional fields** bilen gizläň.

## Ädim 4 — Ýatda saklaň

1. **Save** saýlaň.
2. Sanawa gaýtmak üçin **Save and Close** ulanyň.

![Ýatda saklandan soň](../../../assets/screenshots/v2026.08/tk/person-edit-employee-step-02-after-save.png)

## Ädim 5 — Sanawda barlaň

**Employees** sanawynda **Personal Number** bilen tapyň we täzelenen maglumatlary barlaň.

!!! success "Täzelendi"
    Jikme-jik forma we sanaw täze bahalary görkezýärse üstünlikli.
