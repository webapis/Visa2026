# CV we şahsy faýl goşmak

Işgär formasynda **CV & personal files** sekmesinden CV ýa-da şahsy faýl ýükläň (diňe işgär).

1. Ishgäri açyň → **CV & personal files** sekmesi.
2. **New** / **New Person Document** → **File** meýdançasyndan faýl saýlaň → **Save**.
3. Sanawda tassyklaň.

Pasport ýa-da diplom skanlary bu sekmede däl — degişli pasport / bilim ýazgysynda **Passport copies** / **Diploma copies**.
