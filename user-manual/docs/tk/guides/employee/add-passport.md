# Işgäre pasport goşmak

Bu gollanma bar bolan işgäre **pasport** ýazgysyny goşmagy görkezýär. Pasportlar işgäriň jikme-jik formasyndaky **Passports** tabynyň içinde döredilýär.

!!! tip "Öňünden"
    Işgär ýazgysy bolmaly ([Täze işgär hasaba almak](register.md)).

!!! tip "Ekran suratlary"
    Suratlar **Iňlis** interfeýsinden (wersiýa **2026.08**).

## Ädim 1 — Işgäri açyň

1. **Employees** sanawyndan işgäri açyň.
2. **Passports** tabynyň görünýänçä garaşyň.

![Işgär jikme-jik formasy](../../../assets/screenshots/v2026.08/tk/person-add-passport-step-01-employee-detail.png)

## Ädim 2 — Passports tab

1. **Passports** saýlaň.
2. **New Passport** düwmesini tapyň.

## Ädim 3 — Täze pasport

1. **New Passport** basyň.
2. Pasport formasynyň açylmagyna garaşyň.

![Täze pasport formasy](../../../assets/screenshots/v2026.08/tk/person-add-passport-step-02-passport-form-new.png)

## Ädim 4 — Hökman meýdanlar

| Meýdan | Giriş |
|--------|--------|
| **Passport Number** | Pasport belgisi |
| **Passport Type** | Sanawdan |
| **Issue Date** | Sene |
| **Expiration Date** | Sene |
| **Authority** | Tekst |
| **Issued Country** | Sanawdan |

![Doldurylan pasport](../../../assets/screenshots/v2026.08/tk/person-add-passport-step-03-passport-fields-filled.png)

## Ädim 5 — Saklaň

1. **Save** basyň.
2. **Passport Number** barlaň.

![Saklanan pasport](../../../assets/screenshots/v2026.08/tk/person-add-passport-step-04-passport-saved.png)
