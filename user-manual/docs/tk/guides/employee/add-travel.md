# Syýahat taryhy goşmak

Ishgär formasynda **Travel Histories** sekmesinden syýahat ýazgysy goşuň (işgär we wagtlaýyn myhman; maşgala agzasyna bu sekme ýok).

1. Ishgäri açyň → **Travel Histories** sekmesi.
2. **New** bölünen düwmesinde ok → **New External Arrival**.
3. **Travel Date**, **Check Point**, **Country** barlaň → **Save**.
4. Sanawda tassyklaň.
