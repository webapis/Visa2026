# Ýaşaýyş salgysy goşmak

**Addresses Of Residence** → **New Address Of Residence**. **Lodging** üçin: **Region** → **City** → **Lodging** → **Expiration Date** → **Save**.

**Lodging** / **Hotel** ýok bolsa formdan **New** — öň gözleg ediň, şol bir ýeri iki gezek goşmaň.
