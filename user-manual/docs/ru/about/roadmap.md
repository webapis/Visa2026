# Дорожная карта руководства

На этой странице кратко описано, что доступно сейчас и что планируется дальше. Она обновляется при публикации новых руководств.

## Текущий статус (фаза 2)

| Элемент | Статус |
|---------|--------|
| Сайт руководства (четыре языка) | **Предпросмотр** — черновики входа и навигации |
| Пошаговые инструкции | **Вход** + **навигация** — черновики; регистрация сотрудника далее |
| Зелёная отметка (проверено) | Включается после прохождения тестов |
| Полные отчёты о тестах | Отдельный внутренний отчёт (не на этом сайте) |

## Планируемый порядок руководств

1. Начало работы — вход и навигация  
2. Поиск и открытие персоны  
3. Регистрация нового сотрудника и добавление паспорта  
4. Обновление данных персоны  
5. Создание заявки и добавление позиций  

Продвинутые темы (копии документов, досье, пакеты отчётов, шаблоны) — после базовых задач по персоне и заявкам.

## Публикация

Технический персонал публикует сайт после успешных автоматических проверок. Содержание руководств проверяется на точность перед публикацией.
