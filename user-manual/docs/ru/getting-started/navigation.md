# Основная навигация

В этом руководстве описано, как перемещаться по Visa2026 после входа: домашняя страница, левое меню, списки, карточки записей и панель инструментов.

!!! tip "Предварительно"
    Сначала пройдите [Вход в Visa2026](login.md) — должна открыться **Панель отчётов**.

!!! tip "Снимки экрана"
    Изображения с **английского** интерфейса (версия **2026.08**). Подписи зависят от языка; шаги те же.

## Видеоинструкция

## Оболочка приложения

После входа видны четыре области:

| Область | Назначение |
|---------|------------|
| **Верхняя панель** | Заголовок, значок уведомлений, меню пользователя |
| **Меню навигации** (слева) | Открытие списков и рабочих областей |
| **Основное содержимое** (центр) | Панель, списки или карточки |
| **Панель инструментов** | Действия **Создать**, **Сохранить**, **Обновить** |

![Оболочка приложения](../../assets/screenshots/v2026.08/ru/navigation-step-01-shell.png)

## Домашняя страница — Панель отчётов

После входа открывается **Панель отчётов**. Просматривайте сводные диаграммы и переходите к спискам.

- Переключайте категории
- Нажимайте **Обновить** (справа вверху карточки) для актуальных данных
- Используйте **Открыть список** для просмотра записей

Вернуться можно через **Панель отчётов** в левом меню.

## Левое меню навигации

Состав меню зависит от роли. Обычно сотрудники видят:

| Пункт | Назначение |
|-------|------------|
| **Панель отчётов** | Домашняя страница |
| **Сотрудники** | Записи сотрудников |
| **Родственники** | Записи родственников |
| **Временный посетитель** | Временные посетители |
| **Заявки** | Заголовки заявок |
| **Заявки (через министерства)** / **Заявки (напрямую в миграцию)** | Заявки по типу процесса |
| **Приглашения** / **Отказы** / **Разрешения на работу** | Соответствующие процессы |
| **Операции** | Служебные инструменты |
| **Отчёты** | Пользовательские шаблоны (если разрешено) |

!!! note "Ваше меню может отличаться"
    При отсутствии пункта обратитесь к администратору — не используйте чужую учётную запись.

![Левое меню навигации](../../assets/screenshots/v2026.08/ru/navigation-step-02-left-menu.png)

## Открытие списка

1. В левом меню выберите **Сотрудники**.
2. Дождитесь загрузки списка.

На панели инструментов: **Создать**, **Обновить**, поиск.

![Список сотрудников](../../assets/screenshots/v2026.08/ru/navigation-step-03-employees-list.png)

## Открытие карточки

1. Выберите строку в списке.
2. Откроется карточка записи.

Вкладки (например **Паспорта**, **Образование**) содержат связанные данные.

| Действие | Когда |
|----------|-------|
| **Сохранить** | После изменений |
| **Сохранить и закрыть** | Сохранить и вернуться к списку |
| **Обновить** | Обновить текущий вид |

![Карточка сотрудника](../../assets/screenshots/v2026.08/ru/navigation-step-04-detail-form.png)

!!! warning "Несохранённые изменения"
    Не переходите в другое меню без **Сохранить**.

## Верхняя панель

- **Значок уведомлений** — **Уведомления о состоянии**
- **Меню пользователя** — **Моя учётная запись**, **Сменить пароль**, **Выход**

Полный список: **Операции → Уведомления о состоянии**.
