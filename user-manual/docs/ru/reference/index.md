# Обзор справочника

В разделе **Справочник** будут перечислены бизнес-объекты (персона, заявка и связанные записи) с подписями полей, совпадающими с интерфейсом Visa2026.

Страницы справочника **генерируются автоматически** из каталога приложения в следующем выпуске. Внутренние имена кода не показываются — только подписи, видимые сотрудникам.

## Скоро

- Персона  
- Заявка  
- Позиция заявки  
- Ход заявки
