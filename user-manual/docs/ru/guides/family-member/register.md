# Регистрация родственника

В этом руководстве описана регистрация **родственника** в Visa2026. Запись появится в списке **Family Members**.

!!! tip "Предварительно"
    [Вход](../../getting-started/login.md), [Навигация](../../getting-started/navigation.md) и зарегистрированный **Sponsoring Employee** ([Регистрация сотрудника](../employee/register.md)).

## Шаг 1 — Список Family Members

1. В левом меню выберите **Family Members**.
2. Нажмите **New**.

## Шаг 2 — Заполнение и сохранение

Заполните ФИО, **Personal Number**, данные о рождении, **Sponsoring Employee**, **Relationship**, **Project Contract**, **Company (Subcontractor)** → **Save**.

Вкладка **Family members** в карточке сотрудника только для просмотра.
