# Добавление паспорта родственнику

В этом руководстве описано добавление **паспорта** существующему **родственнику**. Паспорта создаются на вкладке **Passports** в карточке родственника.

!!! tip "Предварительно"
    Родственник должен быть зарегистрирован ([Регистрация родственника](register.md)).

## Шаг 1 — Откройте родственника

1. [Найдите и откройте человека](../person/open-and-search.md) — список **Family Members**.
2. Дождитесь открытия карточки с вкладкой **Passports**.

## Шаг 2 — Новый паспорт

1. Выберите **New Passport**.
2. Заполните обязательные поля → **Save**.
