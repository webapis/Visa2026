# Создание заявки

В этом руководстве описано создание заголовка **application**.

**Два списка заголовков:** **Applications (via ministry)** или **Applications (direct migration)** — см. [Applications — через министерство и прямая миграция](overview.md).

Строки по людям (**application items**) добавляются отдельно.

!!! tip "Предварительно"
    [Вход](../../getting-started/login.md), [Навигация](../../getting-started/navigation.md), [Обзор Applications](overview.md), записи о человеке ([Регистрация сотрудника](../employee/register.md)).

## Шаг 1 — Список заголовков

### Applications (via ministry)

**Applications** → **Applications (via ministry)** → **New** — процедуры с этапом министерства.

### Applications (direct migration)

**Applications** → **Applications (direct migration)** → **New** — прямая миграция.

!!! warning "Списки разделены"
    Заявка через министерство видна только в **via ministry**; прямая миграция — только в **direct migration**.

## Шаг 2 — Тип заявки

**Application Type Code** (три цифры) или **…** → заполняется **Application Type**. Коды фильтруются по выбранному списку.

## Шаг 3 — Поля заголовка и сохранение

Заполните видимые поля → **Save** → **Full Application Number**; **Progress history** сначала пуста (подготовка в офисе подразумевается).

## Шаг 4 — Проверка в том же списке

Найдите заявку в том списке, где создавали; вкладка **Application items** пока пуста.
