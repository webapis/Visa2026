# Пакет отчётов по шаблонам (Resminamalar)

**Templates** (Resminamalar) — Word/Excel шаблоны: каталог, готовность, предпросмотр, ZIP.

Для PDF министерства — [Копии документов](document-copies.md).

## Точки входа

| Область | Где |
|---------|-----|
| Заявка | Деталь Application → **Templates** |
| Строки | Application items → выбор → **Templates** (одна заявка) |

## Шаги

**Templates** → панель → отметить шаблоны → **Download package** → toast → ZIP → **Refresh** после изменений.
