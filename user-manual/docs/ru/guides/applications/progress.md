# Отслеживание прогресса заявки

**Application progress** — хронология шагов workflow. При каждом переходе добавляется **новая строка**, текущий шаг не редактируется на месте.

!!! tip "Предварительно"
    [Обзор Applications](overview.md), [Создание заявки](create.md), [Добавление application items](add-items.md).

## Перед началом

| Пустая история | Файл считается **готовящимся в офисе** |
| Текущий статус | Последняя строка в **Progress history** |

| Маршрут | Первая строка обычно |
|---------|----------------------|
| **via ministry** | Отправлено на рассмотрение в министерство |
| **direct migration** | Процесс начат в миграционной службе |

## Шаги

1. Откройте заявку из нужного списка заголовков.
2. Вкладка **Progress** → **Progress history** → **New**.
3. **State**, **Date**; при необходимости **Process number**, **Ministry letter**.
4. **Save** — обновятся **Status** / **Status date** в списке.
