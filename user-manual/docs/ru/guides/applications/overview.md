# Applications — через министерство и прямая миграция

Visa2026 делит работу с заявками на **два маршрута**. У каждого свой список **заголовков** и список **application items**.

## Два маршрута

| Маршрут | Список заголовков | Список строк |
|---------|-------------------|--------------|
| **Через министерство** | **Applications (via ministry)** | **Application items (ministry)** |
| **Прямая миграция** | **Applications (direct migration)** | **Application items (migration)** |

## Меню Applications (четыре списка)

1. **Applications (via ministry)** — заголовки через министерство
2. **Applications (direct migration)** — прямая миграция
3. **Application items (ministry)** — строки по людям (министерство)
4. **Application items (migration)** — строки (прямая миграция)

## Типичный процесс

1. Откройте нужный список заголовков.
2. **New** → тип и поля → **Save**.
3. Вкладка **Application items** → **New** для каждого человека.
