# Добавление application items

Как добавить строку на человека (**application item**) в сохранённую **application**.

**Два маршрута:** через министерство — **Applications (via ministry)** / **Application items (ministry)**; прямая миграция — **Applications (direct migration)** / **Application items (migration)**. См. [обзор Applications](overview.md).

!!! tip "Предварительно"
    [Создание заявки](create.md) и полные данные персоны.

## Маршруты

| Маршрут | Список заголовков | Список строк |
|---------|-------------------|--------------|
| Через министерство | **Applications (via ministry)** | **Application items (ministry)** |
| Прямая миграция | **Applications (direct migration)** | **Application items (migration)** |

## Шаги

1. Откройте заголовок из **того же списка**, где создавали заявку.
2. Вкладка **Application items** → **New**.
3. Выберите **Person** — поля **Current\*** заполняются → **Save**.

Поиск строк по многим заявкам: соответствующий список **Application items (ministry)** или **(migration)**.
