# Копии документов для министерства (PDF-пакет)

**Document copies** на строках **application item** — проверка сканов, предпросмотр и **ZIP-пакет PDF** для министерства.

!!! tip "Предварительно"
    [Добавление application items](add-items.md); сканы на персоне должны быть прикреплены.

## Где открыть

- **Application items (ministry)** или **Application items (migration)**
- Вкладка **Application items** на заявке

## Шаги

1. Выберите одну или несколько строк → **Document copies** (панель предпросмотра справа).
2. **Linked documents** — статус Ready / Partial / Missing; **gear** для деталей.
3. **Preview** для сканов; **Application form** — скачивание формы.
4. **Package options** (по необходимости) → **Download package** → подтвердите пробелы.
5. Toast **PDF generation** → скачайте ZIP → **Refresh** после новых сканов.
