# Редактирование и синхронизация шаблонов

Редактирование Word/Excel с панели **Templates** и загрузка через **Sync to database**.

## Краткие шаги

1. Откройте **Templates** на заявке.
2. Один раз: **Change template folder** — `%LOCALAPPDATA%\Visa2026\TemplateEdit`
3. Включите **шестерёнку** — появится **Edit template**.
4. Отредактируйте, сохраните, закройте Office.
5. **Sync to database** (файл не должен быть открыт).
6. **Refresh** и **Preview**.

Настройка записей: [Пользовательские шаблоны](user-report-templates.md).
