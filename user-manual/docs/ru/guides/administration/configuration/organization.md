# Настройки организации

Четыре **singleton**: **Company**, **Application Numbering**, **Authorized Signatory**, **Authorized Representative**.

## Кратко

| Меню | Поля |
|------|------|
| **Company** | Название, код бланка, адрес, телефон, e-mail, налог |
| **Application Numbering** | Префикс, формат, padding, seed |
| **Authorized Signatory** | ФИО, должность (Tm), паспорт |
| **Authorized Representative** | ФИО, должность, телефон, паспорт |

Редактируйте **одну строку** в каждом списке. После **Save** обновляются слияния в [Resminamalar](../../applications/resminamalar.md).
