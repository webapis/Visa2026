# Обзор раздела Configuration

Меню **Configuration** задаёт реквизиты организации, нумерацию заявок, маршруты согласования, SLA и лимиты загрузки. Обычно доступно ролям **VisaOffice** / администратор.

## Карта меню

| Пункт | Руководство |
|-------|-------------|
| Company, Application Numbering, Authorized Signatory, Authorized Representative | [Настройки организации](organization.md) |
| Project contracts, Approving ministries, Approval Leg Profile | [Договоры и согласование](contracts-and-approvals.md) |
| Application Migration Sla Profile, Ministry review SLA | [Настройки SLA](sla.md) |
| Document expiration alerts, Upload limits | [Оповещения и лимиты загрузки](alerts-and-upload-limits.md) |

## Шаги

1. Войдите под **VisaOffice** или администратором.
2. Откройте **Configuration** в левом меню.
3. Выберите нужный пункт — для singleton не создавайте дубликаты строк.

Шаблоны отчётов: [Пользовательские шаблоны](../user-report-templates.md).
