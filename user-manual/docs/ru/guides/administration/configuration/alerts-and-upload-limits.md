# Оповещения и лимиты загрузки

**Document expiration alerts** — календарные дни до истечения по типу документа. **Upload limits** — максимальный размер изображений и вложений (МБ), с жёстким потолком сервера.

Для визы и позиции разрешения на работу доступно поле дней до заявления на продление.
