# Договоры и согласование

**Approving ministries** — краткие названия министерств. **Approval Leg Profile** — цепочка согласования. **Project contracts** — договор на заявке, привязан к профилю.

## Шаги

1. Создайте министерства в **Approving ministries**.
2. Задайте порядок **Ministry legs** в **Approval Leg Profile**.
3. Привяжите договоры к профилю, включите **Is Active**.
