# Пользовательские шаблоны отчётов

Для **администраторов**: **Reports → User Report Template** — макеты Word/Excel. Сотрудники видят их в **Templates** (Resminamalar) на заявке.

## Краткие шаги

1. Откройте список **User Report Template**.
2. Создайте запись: **Template Name**, загрузите **Template File**.
3. Укажите **Output Format**, **Root Business Object**, для Excel — **Excel Merge Mode**.
4. Настройте типы заявок, группы, договоры и **Is Active**.
5. **Extract Placeholders** → **Validate Placeholders**.
6. **Placeholder manual** — допустимые токены.
7. Проверьте в **Templates** на тестовой заявке.

Редактирование на ПК: [Редактирование и синхронизация](template-staging.md).
