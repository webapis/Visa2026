# Уведомления о состоянии

!!! danger "Отложено"
    Функция **не** входит в руководство для сотрудников.

Планируемый inbox для сроков и неполных данных. **Сейчас:** **UI-прототип** с примерами; только **администраторы** — **Operations → State notifications**.

Кратко: откройте inbox → фильтры по severity / missing data → читайте карточки. **Sync states** и **Open person** пока демонстрация.
