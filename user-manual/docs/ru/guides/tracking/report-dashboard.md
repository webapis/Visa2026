# Панель отчётов

**Панель отчётов** — домашняя страница после входа: диаграммы по визам, приглашениям, заявкам, регистрации и др.

## Краткие шаги

1. Откройте **Панель отчётов** в меню.
2. На **Обзоре** выберите категорию.
3. Щёлкните сегмент диаграммы — обновится таблица предпросмотра.
4. **Открыть список** — полный список; **Открыть в Excel** — если настроен шаблон.
5. После изменений данных нажмите **Обновить**.

## Поиск лица

В категории **Поиск лица** введите ФИО, личный номер или паспорт; строка откроет [досье лица](../person/dossier.md). См. [Найти и открыть лицо](../person/open-and-search.md).

## Лица с неполными данными

Категория **Лица с неполными данными** — ручной флаг «Неполные данные». См. [Отметить неполными](../person/mark-incomplete.md).
