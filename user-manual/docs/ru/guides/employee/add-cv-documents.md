# Добавление резюме и личных файлов

На карточке сотрудника откройте вкладку **CV & personal files** и загрузите CV или личный файл (только для сотрудников).

1. Откройте сотрудника → вкладка **CV & personal files**.
2. **New** / **New Person Document** → поле **File** → **Save**.
3. Проверьте строку в списке.

Сканы паспорта и диплома — на соответствующих вкладках записи (**Passport copies**, **Diploma copies**), не здесь.
