# Добавление записи о поездке

На карточке сотрудника откройте вкладку **Travel Histories** и добавьте запись о поездке (сотрудник и временный посетитель; у члена семьи этой вкладки нет).

1. Откройте сотрудника → вкладка **Travel Histories**.
2. Кнопка **New** (меню) → **New External Arrival**.
3. Проверьте **Travel Date**, **Check Point**, **Country** → **Save**.
4. Проверьте строку в списке.
