# Добавление записи о зарплате

На карточке сотрудника откройте вкладку **Salaries** и добавьте запись о зарплате (только для сотрудников).

1. Откройте сотрудника → вкладка **Salaries**.
2. **New Employee Salary** → заполните **Amount**, **Currency** → **Save**.
3. Проверьте строку в списке.
