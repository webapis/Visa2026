# Копии документов лица

Просмотр сканов по **мастер-записи лица** в одном каталоге справа. Пакет PDF для министерства — [Копии документов заявки](../applications/document-copies.md).

## Точки входа

| Место | Элемент |
|-------|---------|
| Форма лица | **Person document copies** |
| Список | столбец **•** после **Dossier** |
| Досье | **Document copies** |

## Краткие шаги

1. Откройте каталог в панели предпросмотра.
2. Разделы: паспорта, визы, образование, медзаписи и др.
3. **Preview** или щелчок по строке со статусом **Ready**.
4. **Download** / **Close** в предпросмотре.
5. **Refresh** после добавления сканов.

[Досье лица](dossier.md).
