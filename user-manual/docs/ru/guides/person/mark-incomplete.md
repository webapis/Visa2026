# Отметка «неполные данные» и снятие

В этом руководстве описано, как пометить персону с **неполными** основными данными, записать, чего не хватает, и снять отметку, когда запись готова.

Флаг **Incomplete** — мягкое напоминание; он **не блокирует** создание и редактирование заявок.

!!! tip "Предварительно"
    [Поиск и открытие персоны](open-and-search.md).

!!! tip "Снимки экрана"
    Изображения с **английского** интерфейса (версия **2026.08**).

## Видеоинструкция

## Перед началом

| Нужно | Примечание |
|-------|------------|
| Доступ к спискам персон | Форма **детализации** открыта |
| ≥1 область и **Notes** | Обязательно при **Mark incomplete** |

## Шаг 1 — Откройте форму детализации

![Форма детализации](../../../assets/screenshots/v2026.08/ru/person-mark-incomplete-step-01-detail-form.png)

## Шаг 2 — Mark incomplete

1. На панели инструментов выберите **Mark incomplete**.
2. В окне **Mark person incomplete** отметьте **хотя бы одну** область:

| Флажок | Когда |
|--------|--------|
| **Personal data** | Неполные основные данные |
| **Passport** | Нет паспорта |
| **CV** | Нет CV |
| **Photo** | Нет фото |
| **Education** | Нет образования |
| **Medical** | Нет мед. записи |
| **Address** | Нет адреса |
| **Family docs** | Нет семейных документов |
| **Other** | Другое — опишите в **Notes** |

3. Заполните **Notes** (обязательно).
4. Нажмите **Apply**.

## Шаг 3 — Вкладка Incomplete data

Появляется только при активном флаге. Поля только для чтения: **Missing areas**, **Incomplete notes**, **Incomplete marked on**, **Incomplete marked by**.

![Вкладка Incomplete data](../../../assets/screenshots/v2026.08/ru/person-mark-incomplete-step-03-incomplete-tab.png)

## Шаг 4 — Update incomplete

**Update incomplete** → измените флажки и **Notes** → **Apply**.

## Шаг 5 — Report Dashboard

**Report Dashboard** → категория **Persons with incomplete data**.

![Панель отчётов](../../../assets/screenshots/v2026.08/ru/person-mark-incomplete-step-04-dashboard.png)

## Шаг 6 — Mark complete

**Mark complete** → подтвердите: *Clear incomplete status and notes for this person?*
