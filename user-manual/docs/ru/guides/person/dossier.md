# Досье персоны

Сводная **только для чтения** страница по одному человеку — не форма редактирования.

!!! tip "Предварительно"
    [Поиск персоны](open-and-search.md).

## Точки входа

- **Open dossier** — детальная форма персоны
- Колонка **Dossier** — списки Employees / Family Members / Temporary visitor
- **Person search** — Report Dashboard

## Шаги

1. Откройте досье — дождитесь загрузки.
2. Идентификация и плитки статуса (паспорт, виза, разрешение на работу).
3. **Screen** / **Paper**.
4. **Document copies** — каталог сканов справа.
5. **Export for director** — toast → ZIP для руководителя.
