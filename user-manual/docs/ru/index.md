# Руководство пользователя Visa2026

Добро пожаловать в **руководство пользователя Visa2026 для сотрудников**. На этом сайте пошагово описаны ежедневные задачи с теми же подписями, что и в приложении.

## Что здесь есть

| Раздел | Назначение |
|--------|------------|
| **Начало работы** | Вход, навигация и роли |
| **Инструкции** | Пошаговые задачи (в следующем выпуске) |
| **Справочник** | Справка по полям и экранам из каталога приложения |

## Языки

В верхнем меню можно переключиться между **английским**, **турецким**, **туркменским** и **русским**.

Сначала публикуются руководства на английском; остальные языки следуют той же программе.

**Начните здесь:** [Вход в систему](getting-started/login.md), затем [Основная навигация](getting-started/navigation.md) (уровень 0, черновики).

## Проверенные руководства

Когда руководство проходит автоматические тесты на опубликованной сборке, рядом с названием появляется **зелёная отметка**. Это означает, что шаги проверены в тестовой среде — перед публикацией всё равно требуется проверка сотрудником.

## Помощь

Если экран в приложении не совпадает с руководством, обратитесь к руководителю или администратору системы.
