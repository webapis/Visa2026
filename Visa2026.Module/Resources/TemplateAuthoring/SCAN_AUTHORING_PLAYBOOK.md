# Scan authoring playbook (runtime)

Versioned rules injected into **Create from scan** AI calls. Officers do not edit this file at runtime.

**Sources:** [`docs/USER_TEMPLATE_AUTHOR_GUIDE.md`](../../../docs/USER_TEMPLATE_AUTHOR_GUIDE.md) · [`docs/USER_REPORT_MAP_STANDARD.md`](../../../docs/USER_REPORT_MAP_STANDARD.md) · product spec [`docs/TEMPLATE_AI_SCAN_PRODUCT_SPEC.md`](../../../docs/TEMPLATE_AI_SCAN_PRODUCT_SPEC.md) (S6–S9).

---

## 1. Output

- Emit **Word `.docx` only** (v1).
- Use **simplified layout**: paragraphs, tables, placeholders. Do not attempt pixel-perfect ministry graphics, stamps, or scanned letterhead reproduction.
- Preserve **static boilerplate text** from the scan verbatim where OCR confidence is high.

---

## 2. Placeholder vocabulary

- Every data field must use a token from the **supplied allowed list** only (profile-scoped placeholder set).
- Prefix **`ds.`** on all scalar fields: `{{ds.FullApplicationNumber}}`.
- **Loops:** `{{#ds.rows}}` … `{{/ds.rows}}` for person tables; inside a loop row use `{{.Person_FullName}}` or `{{ds.rows.Person_FullName}}` per validation output — never bare `{{Person_FullName}}` on an Application-root document.
- **Never invent** new merge field names. If no allowed token fits → mark as **gap** (Needs help), leave literal text or `[GAP: label]`, do not emit unknown `{{…}}`.

---

## 3. Field detection

- Map **labels** on the scan to semantic placeholders (e.g. “Arza senesi” → application date token when in allowed set).
- Distinguish **header** vs **roster row** fields using layout (single occurrence vs table column).
- When ambiguous, **ask** (clarification chat) — do not guess between similar date or number fields.

---

## 4. Forbidden AI actions

- Restyle fonts, colors, margins for aesthetics.
- Translate ministry legal paragraphs unless officer explicitly maps a bilingual static block.
- Remove or shorten boilerplate clauses.
- Replace logos with generated art.

---

## 5. Validation discipline

- After generation, every emitted token must pass Extract + Validate against the profile placeholder set.
- Structural loop markers must be balanced (`{{#ds.rows}}` / `{{/ds.rows}}`).
- Image placeholders (`{{IMAGE:…}}`) only when allowed for Word header scope.

---

## 6. Gaps

- Report unmapped scan snippets with suggested English property names for developers only — **do not** add them to the template as working tokens.
- Officer may Approve with gaps acknowledged; Resminamalar may show CHECK until developers extend the catalog.
