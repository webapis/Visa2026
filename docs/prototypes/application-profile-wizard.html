Binding lifecycle (conceptual)

Live FK + per-App values
ApplicationProfile is referenced live (FK). Configuration-related settings always come from the profile. Per-Application fields (Visa Type … Entry Check Point, signatories) are stored on the Application after defaults are applied at create. Profile config edits affect existing Applications; they do not overwrite saved per-Application values.
