How it behaves

1

Selected valueGreen border. Click the name (pen) to open the existing XAF edit popup for that lookup record. × clears it. + outside the box always opens the XAF New popup; the new record is selected on save.

2

Short lists open on clickAbout 15 entries or fewer (Gender, Marital status, Passport type, Relationship) show the whole list on click or focus. Typing still filters.

3

Type to searchDiacritic-insensitive: “turk” finds Türkiye, “inzh” finds Inžhener. Words match in any order. Up to 6 results. Ranked by how many persons already use the value, shown as “Used N×” (“New” when unused).

4

No match creates nothingThe status line points to +. Pressing + opens the New popup with the typed text prefilled in the name. Leaving the box discards unpicked text.

5

Keyboard↑↓ move, Enter picks the highlighted row (or an exact match), Esc closes the list. Enter never submits the wizard.

Same control on: Country of birth, Gender, Marital status, Nationality, Foreign address country, Project contract, Company (subcontractor), Relationship, Sponsoring employee, Passport type, Issued country, Education level / institution / country, Specialty, Position (visa reports), Position (actual / company), Department.

“Not received” keeps working: the box turns amber and read-only, with no +, pen, or ×.
