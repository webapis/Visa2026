| As usage increases | Effect |
|--------------------|--------|
| More verified fixes in **learnings.md** | Next incident skips the same dead-end |
| Same symptom **2+** times | Row in **Scenarios** |
| Stable pattern **3+** times | Short rule in **SKILL.md** or a command in **reference.md** |
| Officer steps change | Update **TEMPLATE_STAGING_EDIT.md** and one learnings entry |

Append a learning only after the officer or a COM/build check confirms the fix. Do not record an unverified hypothesis as a fix.
