# Responsive UI — continuous improvement

**Skill:** [SKILL.md](./SKILL.md) · **Log:** [learnings.md](./learnings.md) · **Reference:** [reference.md](./reference.md)

## The loop

```text
1. READ    → learnings.md + Scenarios
2. MEASURE → this PC when the officer says smallest / this screen
3. TRY     → one section (Overview until others are named)
4. TEST    → hard-refresh; 1280×800 and one wider window; tiles hug text
5. FIX     → CSS in case-workspace.css or the left-menu script
6. RECORD  → append learnings.md
7. PROMOTE → same symptom twice → Scenarios row
```
